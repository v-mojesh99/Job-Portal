# Job Portal (React + Vite)

User (Job Seeker) and Admin (Recruiter) modules with login/signup stored in localStorage.

## Run
    npm install
    npm run dev

## Demo accounts
- User: user@jobportal.com / user123
- Admin: admin@jobportal.com / admin123

## Deploy
Push to GitHub, import on vercel.com (Framework: Vite, build `npm run build`, output `dist`).
